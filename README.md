This is a puzzle game I made using Godot (with C#).

When starting the game, you can choose:
- The width of the puzzle
- The height of the puzzle
- The minimum size of a puzzle piece
- The maximum size of a puzzle piece (although some pieces may end up being larger)

<img width="1116" height="622" alt="Puzzle settings" src="https://github.com/user-attachments/assets/6ab66e90-b5e5-4401-a55b-529e6ccffecb" />

Once you've started a game, you can:
- Select a puzzle piece by clicking on its white container
- Rotate the selected piece
- Place the piece on the grid
- Pick up a piece that has already been placed on the grid
- Return a piece to its original white container by placing it outside the grid

You win when the entire grid is covered with puzzle pieces.
